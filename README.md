# Descend Leaves

A CSS animation of leaves falling around your name.

![Demo](DESCEND-LEAVES/sample.gif)

## Run
Open `DESCEND-LEAVES/DESCEND-LEAVES.html` in a browser. To show your own name, edit the text in the HTML file.

## Tech stack
HTML and CSS (`DESCEND-LEAVES/CSS`), with images in `DESCEND-LEAVES/IMG`.
